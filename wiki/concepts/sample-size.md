# 표본수 해석

급여 표의 `(n=…)`은 해당 평균을 계산하는 데 쓰인 **공고 수**다.

## 위키의 표시 규칙

| 표시 | 의미 | 해석 |
| --- | --- | --- |
| 숫자만 표시 | n ≥ 10 | 일반적으로 참고 가능 |
| ⚠️ | n < 10 | 공고 한두 건이 평균을 크게 바꿀 수 있음, 방향성만 참고 |
| – | 값 없음(n=0 또는 결측) | 해석 불가 |

**n이 1~3인 값으로 증감률을 해석하지 않는다.** 예를 들어 호흡기내과 [[jeonnam|전남]]은 n=2인 값으로 계산돼 -37.0%가 나왔다.

## 실무 원칙

- **증감률은 두 기간 모두 n ≥ 10일 때만 근거로 쓴다.**
- **표본이 작은 진료과는 여러 분기를 이어서 본다.** 한 분기 값보다 추세로 판단한다.
- **표본 부족 항목은 Dataview로 한눈에 볼 수 있다.** [[index|목차]]의 "표본 부족(n<10) 급여 값" 조회를 참고한다.
